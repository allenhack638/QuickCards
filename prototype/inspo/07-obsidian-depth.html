Obsidian Depth

The cards stay matte on the floor; the chrome floats over them as frosted glass, so what you can touch is always one layer up, and the blur never costs a word of contrast.

Design system

One token object drives the page: swatches, the contrast tables (including the worst case behind glass) and the appendix JSON are generated from it. Depth is three levels you can see: the list, glass, raised. Each step up gets a lighter tone, a lit edge and a longer shadow.

Depth and glass

Three levels, each for one kind of thing. Level 0 holds the cards and only the cards. Level 1 is glass: the top app bar (and its search field) and the bottom navigation, a 62 % tint over a 32 dp blur, so the list visibly passes under it. Level 2 is raised and opaque: sheets, groups, toasts. Only t1 sits on glass, and its contrast is computed against a pure white (dark) or pure black (light) backdrop: 4.9:1 and 7.2:1, so it holds even when the blur shows the brightest card.

The same screen on API 31+ and on API 26–30

Below API 31 there is no RenderEffect, so Haze draws its fallback colour: the same tint, opaque (a 95 % tint lets unblurred text ghost through, so we tested and dropped it). A 20 dp gradient edge keeps the sense of the list passing under. The sheet scrim goes from 52 % to 70 % so the list still recedes. Side by side: on 31+ the list visibly travels under the glass; below 31 the chrome is solid and the gradient edge carries the depth.

Colour

The graphite ladder from Obsidian, re-stepped for depth: each level is about 4 % lighter than the one below. Brand red is a fill under white text, at most once per screen. Glass tokens are listed with both their API 31+ and API 26–30 values.

Card bands

Each band keeps its hue at OKLCH lightness 0.42, so white text clears 8:1 on every band and still clears 7:1 under the peak of the sheen.

Typography

Geist for the chrome, Geist Mono only for values you read or copy. The card number is the heaviest type on the screen. Sizes follow Android 14's non-linear font curve.

Shape and spacing

Radius grows with elevation: 10 dp on level 0 parts, 16 dp on the card, 14 dp on floating chrome, 24–28 dp on sheets and dialogs. Spacing is a 4 dp grid.

Spacing scale (dp)

Motion

Springs from the Material 3 token sources, hard-coded as QcMotion. Expressive springs (a little bounce) only for two rare moments: unlock and a card landing. Toasts, sheets and the chip use the calm standard springs. The sheen runs once, after a new card lands, and never again for that card.

Iconography

Material Symbols Rounded, weight 400, optical size 24, grade −25 on dark. Outline by default, filled only for selected or on. Bundled as vector drawables in the app.

Card rendering recipe

The Obsidian slab, plus one layer: the sheen sits between the light and the type, so it can never sit on top of a digit. Everything else is two gradients, a cached noise tile, inset strokes and the groove.

The same recipe in every state

Components

Every control maps to a Material 3 composable, themed through the tokens and routed through the Qc wrappers. Each board is shown dark and light with the states forced; hover, press and keyboard focus also work live.

Feedback lab

The stock snackbar is gone. Copy confirms only on the field itself: the value rolls to “Copied” and back. No timer is shown; the clipboard still clears on the Settings value. Android 13+ adds its own overlay at the bottom left. Everything else is one QcToast, eight dp above the navigation bar.

Moments

The twelve signature moments from R5, plus search opening in the bar. Each plays in a real frame, with its Remove-animations version, the haptic, what TalkBack says, and how the hundredth time differs from the first. Budget: 240 ms the first time, 180 ms after that.

Usability & accessibility

Shown, not listed. Contrast is computed from the tokens, including every text colour over the worst thing that can scroll behind the glass. Touch targets and TalkBack order are measured from the real frames.

All views

Every screen and state at 390 × 844 dp, plus the 1024 dp tablet. Frames marked Live run real behaviour. Dotted underline = new copy this direction needs. Frames tagged Proposed need the owner's OK.

Text budget

Visible words per rendered screen: today, the R1 copy deck's target, and this direction, counted live from the frames on this page. Card data (banks, names, digits), the status bar, the keyboard and system UI are not counted.
