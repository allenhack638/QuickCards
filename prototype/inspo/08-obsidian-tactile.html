Obsidian Tactile.
Cards you can feel.

Each card is a finished object, not a coloured rectangle. Its values are keys: they give under the thumb, lift when they land, and the phone answers with one designed haptic. Calm, because nothing moves that you did not touch, and fast, because the hundredth copy takes 160 ms.

Design system

Every value comes from one token object in this file. Swatches, both contrast tables and the JSON in the appendix are generated from it, and the springs are simulated from the M3 token values at load.

Colour

Obsidian's graphite ladder, unchanged, plus one tactile token: lit, the 1 dp light on the top edge of every raised slab. Brand red is a fill under white, at most once per screen.

Card bands and their finish

Obsidian's sixteen bands at OKLCH lightness 0.42. Each band carries a finish, so a family's cards feel different in the hand while the chrome stays quiet. The corner square is today's shipping colour.

Network plates

Typographic stand-ins on a white plate; the app uses the licensed artwork on the same plate.

Card finishes and the recipe

Seven layers, all affordable in a lazy list on API 26: band, light, finish texture, lit top edge, an engraved groove, type, then the physical drop. No ticket notches: it is a card, not a coupon. The finish never sits above the type, and its brightest pixel is capped, so the number keeps 7:1 on every band (table in Usability and accessibility).

The same recipe in every state

Typography

Geist for the chrome, Geist Mono only for values you read or copy. Sizes follow Android 14's non-linear font curve. The add-card number field uses a hero size so the first thing you type feels like the card itself.

Shape and spacing

Obsidian's radii. Tactile keeps the corners steady on press and squashes the whole slab instead, so a button reads as one object being pushed, not a shape that morphs. 4 dp grid.

Spacing scale (dp)

Elevation

Dark elevation is a tone step, a 1 dp lit top edge and a soft offset shadow. Depth is the lit top edge, the finish and one soft shadow, nothing else: no ledge or second edge under a card. Pressed slabs squash to 0.97: the object goes down, it does not change colour.

Motion: springs with a budget

The four M3 springs below are simulated from their damping and stiffness and drawn as true curves; the page uses the same curves as CSS linear() easings. Frequent actions use the no-bounce springs; only rare moments may overshoot. Every moment fits 240 ms the first time and 180 ms after.

Haptic language

One haptic per action, on the result, never on the press. Each constant gets one meaning across the app. Patterns are drawn for reading only; the phone plays its own. View.performHapticFeedback respects the system Touch feedback setting.

Iconography

Material Symbols Rounded, weight 400, optical size 24, grade −25 on dark. Outline by default, filled only for selected or on.

Components

Every control maps to a Material 3 composable, themed through tokens. Each board renders dark and light with states forced; press, hover and focus also work live.

Feedback lab

Every toast and every copy state, live. Copying never raises a toast or a timer: the copied key lifts and reads ✓ Copied, and that is the whole confirmation. Switch the API level to see it beside the Android 13 clipboard overlay.

Signature moments

The twelve moments from the UX journey work, each playable. Play the first time, play the hundredth, or play with Remove animations. Every moment lists its haptic, what TalkBack says and its time.

Usability & accessibility

Measured, not listed. The contrast tables are computed from the tokens and include the worst texture pixel of every finish. Touch targets and TalkBack order are measured from the frames on this page.

All views

Every screen and state at 390 × 844 dp, with the minimal copy deck. Tap any card value to copy, hold the number or CVV to show it. Dotted = copy not yet in strings_*.xml.

Text budget

Visible words per screen: today's app, the minimal copy deck's target, and this variant counted live from its own frames. Card data (banks, names, numbers, tags) is not copy and is not counted.
