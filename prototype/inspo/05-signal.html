Signal.

QuickCards as a precision instrument: monochrome black and Nothing-grey, a strict grid, and one red button. Each card is a solid block of its band colour with the stub’s corner cut away. Its number sits in a dot-matrix display that lights only the four digits you need. Everything you copy or read aloud is set in plain mono, sized for a till queue. The chrome is quiet so the card, and your thumb, can be loud.

Light only what matters.Masked digits are unlit cells, not noise. The last four are the brightest thing on screen; a reveal lights the rest.
Values are plain, chrome is strict.Doto appears only on the card face and large counts. Every copied value is Space Mono at AAA contrast.
Where the thumb is.Search and filter dock at the bottom, every copy target is a full-height cell, and every primary action sits in the lower half.

What changes versus the current QuickCards

  1. The card becomes the colour object: a solid band block with a 12 dp cut corner from the Stub Lock mark, replacing the 48 dp gradient strip on a grey slab.
  2. The number is a dot-matrix display: unlit cells for masked digits, lit last four, and a left-to-right “light up” on reveal. A plain mono fallback is one switch away and kicks in automatically with high-contrast text.
  3. Card state lives on the tear line: a sash reads Expired, Archived or Check details where the stub tears off, so it never covers a value.
  4. Search and filter move to a bottom dock above the navigation bar, within thumb reach; the app bar keeps the large title, the card count and Add.
  5. Selection is inverted ink everywhere (nav, chips, switches, “All”), giving 3:1+ non-text contrast where the current 1.38:1 fills fail. The red stays the one action fill.
